Quick Convert 빠른 변환

상단 Universal Input 에 짧은 상수든 긴 덤프든 붙여넣으면 HEX / DEC / BIN / OCT / ASCII 를 한 번에 보여준다. 주소 더하기도 된다. 예: 0x401C04+7 → 0x401C0B. 헤더의 8 / 16 / 32 / 64 는 레지스터 하위 비트 해석용. Ctrl+Enter 또는 Calculate.

Usage 사용법 · 용어 찾기

        
영어 이름이 기억 안 나면 여기만 보면 된다. 단어 뜻을 먼저 보고, 아래에서 도구를 고른다.


        
자주 까먹는 단어

        

          

            
              
영어한국어한 줄 설명

            
            
              
HEX16진수0~9, A~F. 예: 0x41 = 65 = 문자 A

              
DEC10진수평소에 쓰는 숫자. 65, 1094861636

              
BIN2진수0과 1. 컴퓨터가 실제로 다루는 비트

              
OCT8진수0~7. 유닉스 권한 0755 같은 데 나옴

              
ASCII문자숫자 코드를 글자로. 0x41 → A, 0x20 → 공백

              
Bytes바이트 배열8비트 묶음. 41 42 43 44

              
Bit비트0 또는 1 한 자리. 8비트가 1바이트

              
Nibble니블4비트 = HEX 숫자 하나. 0xA 는 1010

              
Signed부호 있는 정수음수 가능. 8bit 0xFF = -1

              
Unsigned부호 없는 정수0 이상만. 8bit 0xFF = 255

              
Endian엔디안바이트를 앞에 둘지 뒤에 둘지. intel은 보통 Little

              
Big Endian빅 엔디안큰 자리 바이트가 먼저. 12 34 56 78

              
Little Endian리틀 엔디안작은 자리 바이트가 먼저. 78 56 34 12

              
AND논리곱둘 다 1이어야 1. and eax, 0xff → 하위 1바이트만 남김

              
OR논리합하나라도 1이면 1. 비트를 켜는 용도

              
XOR배타적 논리합서로 다르면 1. 암호/난독화에 매우 자주 나옴

              
NOT비트 반전0↔1. 1의 보수

              
SHL왼쪽 시프트비트를 왼쪽으로 밀기. 빈자리는 0. 대략 ×2

              
SHR오른쪽 시프트오른쪽으로 밀기. 빈자리는 0. 대략 ÷2

              
SAR산술 오른쪽 시프트SHR인데 부호 비트(맨 앞)를 유지. 음수가 음수로 남음

              
ROL / ROR왼쪽/오른쪽 회전밀려 나간 비트가 반대쪽으로 다시 들어옴

              
Two's Complement2의 보수음수 표현. 비트 뒤집고 +1. 5 → -5 비트패턴

              
BSWAP바이트 스왑정수 안의 바이트 순서를 뒤집음. 엔디안 변환

              
Popcount1의 개수켜진 비트 몇 개인지

              
Parity패리티1의 개수가 짝수인지 홀수인지

              
Base64베이스64바이너리를 글자(A-Za-z0-9+/)로 인코딩

              
Mask마스크원하는 비트만 남기는 값. 0xFF, 0x0F 등

            
          

        


        
위쪽 Universal Input

        
아무거나 붙여넣으면 HEX·10진·2진·8진·문자로 동시에 보여 준다. 길어도 된다.

        
    
          
  • 예: 0x401C04+7 → 0x401C0B (주소 더하기)
    • 
          
  • 예: 0x41424344 → 문자 ABCD, 리틀엔디안 44 43 42 41
    • 
          
  • 예: 41 42 43 44 처럼 공백 있는 HEX 덤프도 인식
    • 
          
  • 예: 01000001 긴 0/1 은 2진으로 본다
    • 
          
  • 형식이 애매하면 위 Format 버튼으로 HEX / DEC / BIN / OCT / ASCII 를 강제
    • 
          
  • 헤더의 8/16/32/64 는 레지스터 폭이다. 전체 값은 잘리지 않고, 아래쪽에만 “32-bit signed” 같은 해석을 붙인다
    • 
          
  • 계산: 입력 후 잠깐 기다리거나 Calculate / Ctrl+Enter
    • 
          
  • 결과 오른쪽 Copy. 화면이 잘려 보여도 Copy 는 전체
    • 
        

        

        
각 메뉴가 하는 일


        

          
Quick Convert — 빠른 변환

          
상단 입력칸이 본체. 상수를 하나 만났을 때 제일 먼저 여기.

          
언제: cmp eax, 0x41424344 의 값이 문자인지, 엔디안을 바꾸면 뭔지 보고 싶을 때

          
        


        

          
Address — 주소 더하기

          
베이스 주소 + 오프셋. 비트 폭으로 자르지 않는다. 0x401C04 + 7 = 0x401C0B 를 10진과 함께 보여 줘서 증명할 수 있다.

          
언제: jmp/call 목적지, base + i*4, 구조체 필드 오프셋

          
        


        

          
Bitwise — 비트 연산 (AND / OR / XOR / NOT)

          
두 수 A, B 를 넣고 논리 연산을 한 번에 본다. 결과는 HEX·10진·2진.

          
언제: and eax, 0xff / or al, 1 / xor eax, 0x1337

          
        


        

          
Shift / Rotate — 밀기 / 회전

          
SHL·SHR·SAR 는 밀기, ROL·ROR 는 회전. 비트 폭만큼 돌아간다.

          
언제: rol eax, 5 / shr al, 1 / sar eax, 2

          
    
            
  • ROL8(0x81, 1) = 0x03   (10000001 → 00000011)
    • 
            
  • ROR8(0x01, 1) = 0x80   (00000001 → 10000000)
    • 
          

          
        


        

          
XOR — 배타적 논리합

          
숫자 XOR, 문자열 XOR, 키가 반복되는 XOR, 1바이트 키 전부 대입(브루트포스).

          
언제: 문자열이 이상하게 깨져 보이고, 키가 한 바이트거나 “KEY” 처럼 반복될 때. printable 점수 높은 후보가 위로 온다.

          
        


        

          
String / Bytes — 문자 ↔ 바이트

          
ABC ↔ 41 42 43, 문자 ↔ 2진. HEX 는 붙여쓰기, 공백, 콜론, \x41 모두 됨.

          
언제: 패킷/파일 앞부분을 글자로 읽고 싶을 때, 셸코드 HEX 를 ASCII 로 볼 때

          
        


        

          
Endian — 바이트 순서

          
12 34 56 78 → 78 56 34 12. 2/4/8 바이트 단위. BSWAP 은 정수 통째로 뒤집기.

          
언제: IDA/gdb 에서 본 eax 값과 메모리 덤프 순서가 안 맞을 때. x86은 보통 Little Endian.

          
        


        

          
Integer — 정수 / 2의 보수

          
같은 비트를 8/16/32/64bit signed·unsigned 로 같이 본다. 2의 보수로 부호 반전도 함.

          
언제: 0xFFFFFFFF 가 -1 인지 4294967295 인지, cmp 직후 조건을 볼 때

          
        


        

          
Encoding — Base64 / URL

          
글자를 Base64 또는 URL 인코딩/디코딩. 보조 기능.

          
언제: 설정 문자열이 SGVsbG8= 처럼 보이거나, %20 이 섞여 있을 때

          
        


        

          
HEX Dump — 헥스 덤프

          
왼쪽 주소, 가운데 HEX, 오른쪽 ASCII. 짧은 버퍼를 파일 덤프처럼 봄.

          
언제: 문자와 HEX 를 나란히 보고 싶을 때

          
        


        

          
Bit Viewer — 비트 자리 보기

          
어느 비트 번호가 1인지. test eax, 0xA5 마스크 분석.

          
언제: “7번 비트가 켜져 있나?” 를 눈으로 확인할 때
